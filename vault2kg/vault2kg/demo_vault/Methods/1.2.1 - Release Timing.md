# 1.2.1. Release Timing

**Team:** Biomechanics  
**Risk:** R3

**Systems:** Data warehouse

## Method

Release timing is computed from the wrist keypoints of 1.1.2. Tom Becker showed that timing based on MediaPipe comes out about 40 ms late, so only ViTPose keypoints are used here. The results feed the weekly report.
