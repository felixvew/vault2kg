# 1.1.1. Video Intake

**Team:** Imaging  
**Risk:** R1

**Systems:** Camera rig AND Lab server

## Method

Trials are filmed with the four-camera rig and copied to the lab server every evening. File names carry the athlete code and the date, so later steps can find them. The intake checks frame rate and resolution before anything else runs, and refuses videos without a signed consent form (see 2.2.1).
