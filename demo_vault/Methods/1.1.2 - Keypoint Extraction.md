# 1.1.2. Keypoint Extraction

**Team:** Imaging  
**Risk:** R2

**Systems:** Lab server AND GPU node

## Method

MediaPipe extracts body keypoints from every video that 1.1.1 accepted; final analyses use ViTPose, because MediaPipe loses the wrist during fast releases. Results go to the data warehouse as one table per session.
